# Omini-Flash 10秒 Target 服装货架上身滑稽大笑 Skill

为 `omini-flash` 生成一条原生 10 秒、9:16、真实手机 UGC 风格的美区 TikTok 视频提示词。

固定叙事：

```text
0.0-2.0秒：普通成年黑人女性在明亮 Target 风格服装区发现产品
→ 眼神变化时摄影机立即平滑右移
→ 右移已经开始后冰咖啡才脱手
→ 产品占据画面
→ 约2.0秒唯一一次硬切
2.0-4.0秒：产品挂在整齐服装货架的醒目位置
→ 一件前景衣服短暂遮满镜头，形成购买后的无缝时间跳转，不是硬切
4.0-8.6秒：进入本条视频唯一确定的群体展示方案，至少两名成年人同框
8.6-10.0秒：穿戴者与现场成年人因为服装造型共同自然大笑
```

全片不介绍产品、不讲痛点和卖点、不做功能验证、不做购买引导、不指向画面角落。

## 1. 输入与事实优先级

生成前读取全部已上传资料，优先级固定为：

1. 产品参考图；
2. `product_profile.yaml`；
3. 用户确认或修改后的展示组合、穿戴方式和原创变化点；
4. 用户对当前视频的额外要求。

只使用资料明确支持的产品事实。禁止补充认证、安全结论、功能效果、隐藏结构、额外配件和不存在的穿戴结果。

## 2. 原创变化与查重规则

降低重复风险必须依靠结构变化，不得只替换人物衣服颜色、发型和背景装饰。每次生成前静默建立以下内容指纹：

```text
group_variant：三人同穿 / 派对反应 / 家庭揭晓
wearer_count：实际穿着产品的人数
reactor_count：未穿产品但参与反应的人数
location：家庭客厅、家庭卧室、后院聚会中的一个确定地点
camera_pattern：固定中广景、轻微手持跟随、门口揭晓中的一个确定方式
showcase_action：并排站立、同步转身、走入人群、门口亮相中的一个确定动作
reaction_beat：共同忍笑、先愣住后大笑、互相看一眼后大笑中的一个确定反应
visual_surface：人物组合、服装配色、家具布局和货架相邻衣服配色
```

要求：

- 每条视频只选择一个 `group_variant`，不得把三个方案塞进同一条 10 秒视频；
- 默认优先选择“派对反应”，批量生成时按“派对反应 → 三人同穿 → 家庭揭晓”轮换；
- 与最近一条相比，至少改变一个结构维度：`group_variant`、`location`、`camera_pattern`、`showcase_action`；
- 与最近一条相比，至少改变三个可见维度：人物组合、穿戴人数、反应人数、构图、动作、环境布局、结尾节奏；
- 不得连续两条使用相同的 `group_variant + location + showcase_action + reaction_beat` 组合；
- 批量生成时不得连续两条使用相同穿戴人数和相同结尾动作；
- 若用户提供最近生成记录，读取最近 12 条内容指纹并避开完全相同组合；
- 若没有历史记录，使用默认派对方案，同时生成与当前产品和人物关系直接相关的原创动作；
- 不照搬现有创作者的台词、镜头顺序、标志性动作和布景；不引用“爆款同款”“复刻某视频”等表达；
- 这些规则用于提高原创性，不承诺绕过任何平台审核、版权判断和重复内容检测。

前 4 秒的叙事因果保持固定，但允许静默变化主角发型、上衣颜色、开场景别、相邻货架服装配色和咖啡脱手时间。摄影机始终先开始右移，咖啡随后才脱手。

## 3. 两阶段流程

### 第一阶段：只确认三项

收到资料后只输出：

```text

穿戴方式：……

原创变化点：……
```

要求：

- 所有展示人物必须是成年人；
- 展示组合必须从三个群体方案中选择一个确定方案；
- 明确产品属于完整外穿服饰还是需要叠穿的服饰，并严格按参考图的正常方式穿戴；
- 明确本次与上一条不同的结构变化和可见变化；
- 滑稽感只来自产品造型和人物之间友好的共同反应；
- 不生成时间轴和完整提示词；
- 输出后停止，等待用户确认。

### 第二阶段：生成提示词

用户确认并回复“提示词”“生成”“按这个做”或明确要求视频提示词后，只输出：


## 4. 产品外观锁定

最终提示词必须按以下顺序锁定产品：

```text
1. 数量：货架展示样品与上身样品的数量关系
2. 类别与主轮廓：腰部服饰、短裤、围裙、裙装、背心或其他具体类别
3. 正面与背面：颜色分区、图案位置、系带、开口和覆盖范围
4. 材质与比例：软硬、厚薄、长宽比例及相对人体尺寸
5. 穿戴位置：腰线、腿口、肩带或其他结构的准确位置
6. 反向禁止：三至六种最可能被误生成的相近产品和错误结构
```

对带人体错觉印花的成人滑稽服饰，必须额外写明：

```text
图案是印在布料上的夸张漫画式视觉错觉，始终能看出是服装印花。
若产品本身是完整外穿短裤，直接正常穿着产品，不增加可见打底短裤和紧身裤。
产品面料必须不透明，并从腰部到裤脚完整覆盖真实身体。
不得把印花变成真实皮肤、真实裸体或真实生殖器官。
不得使用胯部或臀部特写，不做顶胯、拍打和性暗示动作。
```

若参考图与本次示例一致，锁定为：红白蓝配色的成人滑稽腰部服饰，左侧深蓝底白色星星区域，右侧红白横条区域，腰部有可见白色系带；正反面均为印在布料上的夸张漫画式身体错觉。不得改成普通美国国旗短裤、泳裤、比基尼、真实裸体、充气服装或普通围裙。

当参考图显示产品为完整的成人外穿沙滩短裤时，必须把它定义为可单独外穿的完整短裤。人物按普通短裤的方式直接穿着，产品裤脚下方不得露出骑行短裤、紧身裤和其他额外打底层。不得将完整短裤误写成需要套在其他裤子外的装饰罩裤。

## 5. 固定时间结构

### 0.0-2.0秒：发现产品与平滑右移

- 场景固定在明亮、整洁的美国 Target 风格服装区；
- 不生成可识别的 Target 字样和圆靶 Logo；
- 主角是一名普通美国成年黑人女性消费者，不是店员、导购和代言人；
- 开场主角位于画面左侧偏中，面向右侧陈列；
- 她左手拿无文字透明杯装冰咖啡，右手提无文字纯红色塑料购物篮；
- 她看到产品时眼睛骤然睁大，摄影机在眼神刚变化时立即以固定高度和焦段平滑右移；
- 摄影机已经右移约 0.2 秒后，冰咖啡才从左手意外脱落并垂直下落；
- 摄影机只追向产品，不拍咖啡落地，不跟随咖啡，不回头和停顿；
- 主角、购物篮和下落咖啡随横移自然退出画面；
- 横移结束时，同一套产品完整、清晰地占据画面；
- 第一镜头不取货、不穿戴、不口播、不触碰产品；
- 不出现围观、争抢、空货架、最后一件、售罄和低库存暗示。

### 约2.0秒：唯一一次硬切

执行全片唯一一次清楚硬切。硬切到同一 Target 风格服装区的服装货架正面视角。

硬切后：

- 整齐排列的普通无品牌衣服填满服装货架；
- 同一套产品使用普通无文字衣架，挂在货架视觉中心的醒目位置；
- 产品周围有正常数量的衣服，不制造稀缺感；
- 产品正面朝向镜头，轮廓、图案、系带和比例清楚；
- 冰咖啡和红色购物篮不再出现；
- 不出现文字、品牌、价格牌、促销牌和平台 UI。

### 2.0-4.0秒：服装货架展示

- 使用稳定的中景，让醒目位置的产品成为视觉中心；
- 镜头只展示货架陈列，不介绍产品，不出现口播；
- 在 3.7-4.0 秒，一件普通前景衣服由画面一侧自然掠过并短暂遮满整个镜头；
- 使用这次完整遮挡完成“已经购买并进入群体展示场景”的无缝时间跳转；
- 这不是硬切、闪白、溶解、变形或产品在镜头前自动穿上；
- 遮挡前是商店服装货架，遮挡后必须是本条选定的家庭或派对群体场景，不得仍在商店；
- 场景允许从商店暖白灯光变化为家庭自然日光或派对暖光，但主角身份和产品外观保持一致。

### 4.0-8.6秒：购买后的群体穿着展示

遮挡结束时，时间已经推进到购买完成之后。静默选择并执行以下三个方案中的一个；最终提示词只能写入被选中的方案，不得保留其他方案名称和多选描述。

#### 方案A：三人同穿

- 场景固定为明亮的家庭客厅或后院聚会区，并在最终提示词中确定其中一个地点；
- 同一主角与另外两名外貌、体型和服装明显不同的成年朋友并排出现；
- 三名成年人各自穿着一条完全相同的滑稽外穿服饰，因此本方案明确出现三条同款产品；
- 三人先正面并排站立，再同步完成一次轻松半转身，展示正面和背面；
- 三人的脸、手臂和身体不得复制、融合和互换，产品图案与结构必须完全一致。

#### 方案B：派对反应，默认方案

- 场景固定为明亮整洁的家庭客厅派对，至少五名成年人自然分布在画面中；
- 同一主角穿着一条滑稽外穿服饰走入朋友中间，其他人穿普通休闲服且不穿同款产品；
- 朋友们先短暂愣住，随后看向产品造型并与主角一起大笑；
- 画面始终保留主角全身产品和至少三名朋友的清楚反应；
- 笑声针对滑稽服装设计，主角主动参与笑声，不表现羞辱、排斥和身体嘲讽。

#### 方案C：家庭揭晓

- 场景固定为主角自己的明亮客厅，至少两名成年朋友坐在沙发附近等待；
- 同一主角穿着一条滑稽外穿服饰从卧室门口走进客厅，在朋友面前完成一次自然转身；
- 两名朋友先互相看一眼，再看向主角的滑稽造型并共同大笑；
- 主角始终与至少两名朋友同框，不得出现独自试穿和独自拍摄的画面。

所有方案共同要求：

- 使用头到膝盖或全身中广景，让穿戴者、产品和群体关系同时清楚；
- 产品按参考图作为完整外穿服饰正常穿着；
- 产品面料本身不透明并完整覆盖真实身体；
- 对完整外穿短裤，裤脚下方不得露出骑行短裤、紧身裤和其他额外打底层；
- 不口播、不指卖点、不触摸敏感部位、不顶胯、不拍打臀部、不摆性暗示姿势；
- 不加入产品特写、功能演示和独自主角展示。

### 8.6-10.0秒：群体大笑收尾

- 保持选定方案的同一地点、同一人物数量和同一产品数量；
- 穿戴者与现场朋友因为服装造型共同自然大笑；
- 笑声短促、真实、友好，不尖叫、不嘲笑穿戴者、不做夸张跌倒；
- 至少两名成年人和一名穿戴者始终清楚同框；
- 不说 CTA，不指向左下角，不出现购买手势；
- 最后 0.4 秒保持群体关系、完整产品和笑脸清楚同框。

## 6. 人物、场景与连续性

跨场景固定：

```text
同一名成年黑人女性
同一发型和妆容
同一款产品的颜色、图案、结构和尺寸
选定方案中的人物数量、穿戴人数和产品数量
```

场景顺序必须固定为：0.0-4.0 秒位于 Target 风格服装区，4.0-10.0 秒位于本条选定的唯一群体场景。遮挡转场必须明确表达购买后进入群体场景的时间跳转，4 秒后不得残留商店货架和零售陈列。第一镜头的购物篮和咖啡只用于发现动作。

同一主角必须在 4 秒后的群体场景中继续出现，但不得独自展示。新增成年人必须拥有不同的脸型、发型、体型和普通服装，不得由主角复制产生。方案A固定三名穿戴者和三条同款产品；方案B固定一名穿戴者和至少四名反应者；方案C固定一名穿戴者和两名反应者。商店与群体场景光线可以不同，但产品颜色、图案和结构不得改变。

## 7. 声音与表演

- 0.0-8.6 秒不使用口播；
- 0.0-4.0 秒允许服装店自然环境声、衣架轻响和咖啡杯脱手声；
- 4.0 秒后环境声自然切换为选定群体场景的轻微室内或后院底噪；
- 8.6-10.0 秒保留穿戴者与朋友自然重叠的笑声；
- 不使用旁白、字幕、背景音乐和罐头笑声；
- 不让笑声提前出现在上身展示阶段。

## 8. 安全与内容限制

- 所有人物必须明确为成年人；
- 滑稽感来自服装设计，不来自身体羞辱、种族刻板印象或性骚扰；
- 对人体错觉印花，只呈现其为布料图案，不生成真实裸露；
- 产品本身必须使用不透明面料并完整覆盖真实身体；
- 完整外穿短裤直接正常穿着，不增加可见打底裤；
- 禁止真实生殖器官、乳头、臀沟和透明衣物；
- 禁止儿童、青少年和年龄不明确的人物；
- 禁止低角度胯部镜头、胯部特写、臀部特写和慢动作身体扫拍；
- 群体笑声必须是共同参与的友好反应，不得表现霸凌、羞辱、排斥和身体嘲讽；
- 禁止绝对效果、社会证明、虚假稀缺和购买催促。

## 9. 单一执行路径

Skill 可以在生成前从方案池中选择，但最终提示词必须固定一个群体方案、一个地点、一个人物数量、一种穿戴方式、一个遮挡转场、一个展示动作和一种群体反应。最终提示词不得出现方案A、方案B、方案C，不得使用“或”“任选”“可以”等方式提供多选路径。
