# Omini-Flash 10秒 Target 惊喜货架开头产品介绍 Skill

本 Skill 专门用于 `omini-flash` 的原生 10 秒竖屏产品介绍视频。

固定主逻辑：

```text
第一镜头：黑人女士在明亮 Target 商超通道中发现产品
→ 左手冰咖啡，右手红色 Target 购物篮
→ 她眼睛骤然睁大，摄影机立刻开始持续向右平移
→ 平移已经进行时，左手冰咖啡才脱手下落
→ 主角和咖啡自然退出画面，货架产品完全占据画面
→ 明确硬切一次
第二镜头：同一位女士已拿起同一套展示样品
→ 正对观众主观镜头展示产品
→ 从目标人群的真实生活烦恼切入
→ 手持产品介绍一个最相关的已验证卖点
→ 软性转化并指向左下角
```

开头的好奇心必须来自“观众先看见一位普通购物者在通道中发现某个产品，眼神变化时摄影机已经开始平滑右移；镜头持续右移期间，冰咖啡才意外脱手，直至产品完整占据画面”。不得把这段写成“惊讶后停顿，再掉咖啡，再移镜”的连续步骤。不得停留拍摄咖啡落地，不得跟随咖啡，不得让主角或咖啡停留在镜头边缘。不得把开头改写成多人围观、抢购、空货架、最后一件库存、主角一开始已经面对镜头介绍。

货架上的产品是一个开放展示位中的单一展示样品，不表示真实库存只剩一件。不得出现“最后一件”“仅剩一个”“库存不足”“售罄”文字、台词、空货架暗示和争抢动作。

本 Skill 的核心是“购物者发现时镜头立即右移 → 镜头持续右移期间咖啡脱手 → 产品完全占据画面 → 主角手持直接介绍”，不是功能验证，不是多场景剧情，不是产品详情板，也不是虚假稀缺叙事。

默认生成一条原生 10 秒视频，视频内部固定使用两个镜头，只允许在约 2.0 秒处硬切一次。这里的“双镜头”仍然是一条视频，不等于生成两条视频拼接。不得把 15 秒内容强行塞入 10 秒，也不得要求 Omini 在同一连续镜头内同时完成反应、摄影机横移、取货、转身、介绍和摄影机绕位。

## 1. 适用范围

适合：

```text
厨房工具
家庭清洁工具
宠物用品
收纳用品
旅行用品
汽车用品
日常小工具
结构简单的家居用品
```

不适合自动使用本 Skill 的产品：

```text
必须精确安装才能理解的产品
必须完整穿戴才能理解的产品
需要长时间反应才能证明效果的产品
涉及承重、防水、防火、防烫、安全保护的产品
需要复杂前后对比才能成立的产品
需要医疗、健康、卫生功效证明的产品
```

遇到以上产品时，仍可介绍产品外观、结构和用途，但不得加入功能验证。

## 2. 输入优先级

生成前必须读取全部已上传资料。

优先级固定为：

1. 上传的产品参考图；
2. `product_profile.yaml`；
3. 用户确认或修改后的人群、痛点、卖点；
4. 用户针对当前产品的额外要求。

参考图是产品外观最高优先级。

`product_profile.yaml` 只用于读取资料明确支持的内容：

```text
产品数量
颜色
材质
形状
尺寸关系
正反面结构
关键标签位置
真实用途
已确认卖点
must_keep
must_avoid
```

禁止自行补充认证、安全结论、抗菌功能、防霉功能、治疗功能、绝对清洁效果、隐藏结构、额外配件和资料未写明的使用结果。

## 3. 强制两阶段流程

### 第一阶段：只确认三项内容

收到产品资料后，只输出：

```text
目标人群：……

核心痛点：……

核心卖点：……
```

要求：

- 只给一个明确目标人群；
- 只给一个核心痛点；
- 只给两个至四个明确卖点；
- 内容直接、简短；
- 不解释产品事实；
- 不列次要痛点；
- 不给多个方向；
- 不分析风险；
- 不给推荐度；
- 不生成时间轴；
- 不提前生成提示词。

输出完成后停止，等待用户确认。用户修改其中任何一项后，以用户最新版本为准。

### 第二阶段：生成 Omini 10 秒提示词

用户确认三项内容，回复“提示词”“生成”“按这个做”或明确要求视频提示词后，立即输出完整提示词。不要再次复述人群、痛点和卖点分析。

最终只输出：

```text
video_generation_prompt:

[完整可直接提交给 omini-flash 的中文提示词]
```

## 4. 人群、痛点与卖点规则

人群必须包含一个具体的高频行为。

错误：

```text
家庭用户
所有旅行者
所有做饭的人
需要收纳的人
```

正确：

```text
经常短途出差、总想把更多换洗衣物装进行李箱的旅行者
经常在家处理肉类、在意备菜后清洁麻烦的家庭用户
经常整理衣柜、缺少分类空间的家庭用户
```

痛点必须来自真实行为，固定提取顺序：

```text
目标人群 → 经常做什么 → 最烦哪个后续步骤 → 产品哪个卖点能回应这个麻烦
```

痛点只负责共鸣，不负责制造恐惧。禁止默认使用细菌、发霉恐惧、食物中毒、过敏、疾病、伤害、事故、虫害、火灾和严重脏污作为开场。

Omini 只有 10 秒，中段只能承载一个主卖点，最多附带一个可见结构信息。口播只介绍产品是什么、一个核心结构或材质、一个直接回应痛点的日常价值。不得为了卖点完整而堆叠全部功能。

## 5. Omini 原生 10 秒双镜头时间结构

固定使用一条 10 秒视频内部的两个镜头。只允许一次明确硬切，不得改成全程连续跟拍。

### 0.0–2.0秒：第一镜头——Target 通道发现与平滑横移

- 固定在明亮、整洁的美国 Target 商超内，与产品类别匹配的货架通道；
- 使用固定的中广角观察机位，机位略低于主角眼睛，起始画面稳定；
- 开场第一帧，主角站在画面左侧偏中位置，面向右侧货架；
- 主角必须是一名普通美国成年黑人女性消费者，不是店员、导购、专业人士和品牌代言人；
- 她左手拿一杯透明塑料杯装冰咖啡，棕色咖啡液和冰块可见，杯身无文字；
- 她右手提一只无文字、无标志的纯红色塑料购物篮，以颜色和场景表达 Target 购物氛围，不生成可识别 Target 圆靶 Logo；
- 她先看向右侧货架，眼睛骤然睁大；在眼神刚变化时，摄影机立刻保持同一高度和焦段开始一次不中断的平滑向右移动，速度稳定，不推拉、不旋转、不绕人物；
- 摄影机已经向右移动约0.2秒后，左手的冰咖啡杯才因意外惊讶脱离手掌并开始垂直下落；摄影机保持原有速度持续右移，不因咖啡脱手而停顿、加速和改变方向；
- 摄影机只追向产品，不拍摄咖啡落地，不跟随咖啡，不回头，不减速等待主角反应；
- 横移过程中，主角、红色购物篮和下落咖啡自然退出画面；
- 横移结束时，货架中同一个开放展示位内的一套裸露产品展示样品完全占据画面，货架上的样品摆放整齐；
- 相邻陈列格仍摆放其他无品牌普通同类用品，整排货架不得空置；
- 同款产品只能出现一套，表示该展示位中的单一开放展示样品，不表示最后库存；
- 第一镜头只完成主角发现、开始平滑右移、平移中咖啡脱手和展示产品；
- 第一镜头不取货、不转身面对镜头、不口播、不让主角触碰产品；
- 不出现第二名主角，不出现围观人群，不出现争抢、讨论价格、空货架、低库存、售罄和最后一件暗示。

第一镜头的唯一目的：

```text
让主角眼神变化直接触发一段不中断的平滑右移
→ 在已经开始的右移中让咖啡脱手作为动态证据
→ 右移不中断，直至产品完全占据画面
```

### 2.0秒：唯一硬切与连续性锚点

在约 2.0 秒处使用一次清楚硬切。

硬切前后的事实必须一致：

```text
同一名主角
同一套服装和发型
同一 Target 商超货架通道
同一产品展示位
同一组暖白光线
同一套展示样品
同一产品颜色、结构、尺寸、方向和长宽比例
```

冰咖啡和红色购物篮只属于第一镜头，不得在第二镜头重新出现。硬切后的第二镜头不重新讲述发现过程。画面直接从“产品已在横移后完整占据画面”切到“主角已经取下同一套展示样品，并正对镜头展示”。

### 2.0–4.0秒：第二镜头——手持产品并完成痛点共鸣

- 第二镜头使用货架正前方的观众主观中近景；
- 主角已经站在原展示位前，已取下同一套展示样品；
- 主角正面对镜头，产品在胸前完整入镜；
- 第一镜头中的冰咖啡和红色购物篮不在第二镜头出现，主角双手只稳定展示同一套产品；
- 产品朝向、横竖方向和参考图一致，不得为了适应人物手持而改变长宽比例；
- 原展示位在主角身后自然空置，但不得出现“最后一件”“缺货”“售罄”和低库存标志；
- 主角使用一句自然美式英语口播，命中目标人群的高频行为和最烦的后续步骤。

推荐句式：

```text
[Do this often], but hate [the annoying aftermath]?
```

要求：一句话、8 至 12 个英文单词、不讲竞品、不拉踩材质、不制造恐惧、不使用技术化描述、不从“Still using...”开始、不从“Tired of worrying about...”开始。

### 4.0–8.6秒：第二镜头——手持产品直接介绍

主角保持原地、同一机位、同一产品，直接介绍产品。只完成一个确定的简单展示动作：

```text
轻微抬起产品
轻微倾斜产品
手指指示一个可见结构
将正面自然转到背面一次
```

实际提示词只能选择其中一个动作，不得同时提供多个动作路径。口播只介绍产品是什么、一个核心材质或结构、一个直接回应痛点的日常价值。

这一段是产品介绍，不是产品测试。默认禁止加入切肉、擦拭、冲水、洗涤、安装、佩戴、宠物行走、前后对比、功能验证、独立产品特写、台面静物镜头、第三镜头、第二使用场景和额外道具。

### 8.6–10.0秒：第二镜头——软性转化

主角继续清楚展示同一套产品，使用一句很短的转化收尾，直接承接日常使用价值。

推荐表达：

```text
That makes everyday packing much simpler.
This could make daily organizing feel a little easier.
That makes everyday prep a lot simpler.
```

实际提示词只使用一个确定句子。

动作要求：

- 一只手稳定产品；
- 另一只手抬起食指，明确指向画面左下角一次；
- 指向角度必须是斜向下，不得变成普通讲解手势、摊手和左右挥动；
- 不反复点击；
- 不生成箭头、价格、折扣、倒计时和平台 UI；
- 最后 0.3 至 0.5 秒保持人物、产品和指向动作清楚同框。

## 6. 口播长度与节奏

10 秒完整英文口播控制在 18 至 25 个英文单词，最多三句话：

1. 痛点共鸣；
2. 产品是什么加核心卖点；
3. 极短转化。

优先将第二句和第三句写短，避免口播过满。禁止一次介绍四个以上卖点、长句堆叠、解释原理、重复痛点、重复产品名称和重复 CTA。

---

## 7. 产品外观锁定

生成提示词前，必须基于上传参考图建立一份“产品外观锁定合同”。参考图的可见事实高于泛化产品名称与 YAML 中的笼统类别词。不得因为产品属于某个常见类别，就改写成模型更常见的同类物。

每条最终提示词的产品锁定段必须按以下顺序写出全部六项，不得省略：

```text
1. 数量：全片只出现几件，产品与配件如何构成一套
2. 主轮廓：具体类别加完整外形，不得只写“板”“袋”“盒”“刷”
3. 方向与比例：横向或竖向，长边约为短边几倍，人物手持时保持同一方向
4. 厚度与边缘：薄片、厚盒、软袋、圆柱等；边缘平整、折弯、圆角、包边等
5. 关键结构：二至五个最不可替代结构，明确其位置、数量、朝向和连接关系
6. 反向禁止：列出三至六个最可能被模型误生成的替代品或错误结构
```

产品锁定段不得使用空泛表达：

```text
不合格：银色金属板，矩形，保持参考图一致。
合格：一块薄型拉丝银色不锈钢台面延伸板，横向长方形，宽度约为高度的1.7倍，板面平整无孔；底部长边是一体式90度向下折弯挂边，形成连续薄金属挂钩。
```

### 7.1 轮廓优先规则

产品名称只能帮助识别用途，不能替代轮廓描述。必须先锁定“从正面看像什么、从侧面看像什么、拿在手里时哪条边朝下”。

```text
普通砧板 ≠ 带折弯挂边的台面延伸板
普通收纳袋 ≠ 带阀门和双密封轨的真空压缩袋
普通托盘 ≠ 带固定挂钩结构的薄金属面板
```

若一个关键结构决定产品类别，必须在最终提示词中出现至少两次：

1. 产品外观锁定段；
2. 第二镜头手持展示段。

禁止只在卖点口播中提及结构。画面结构必须先于口播被锁定。

### 7.2 比例、厚度与边缘强制规则

- 所有扁平产品必须写明横竖方向、长短边比例、厚薄感、四边形态；
- 所有带折弯、挂钩、卡扣、阀门、滑轨、拉环、提手和开口的产品，必须写明该结构位于哪一条边、朝哪个方向、是否连续、与主体是否一体；
- 不得只写“有边缘”“带挂钩”“有阀门”；
- 若参考图中表面平整，必须明确禁止凹槽、把手、围边、脚架和装饰纹路；
- 若参考图中产品薄，必须明确禁止厚盒化、托盘化、桶化和缩小成手掌大小；
- 若参考图中产品宽而扁，人物手持镜头必须保持宽边水平，不得自动变成接近正方形的小板。

### 7.3 平面板、托盘状产品的额外锁定

当产品为金属板、砧板、垫板、托盘、延伸板和面板时，必须额外写清：

```text
板面是否完全平整
板体是薄片还是厚托盘
宽边与短边的比例
下折边、上翻边、挂边或卡接边所在的具体长边或短边
折弯方向是向下、向上、向内还是向外
折弯是否为整条连续结构
```

对于带台面挂边的薄金属延伸板，最终提示词必须包含以下固定约束：

```text
板面完全平整，无孔、无把手、无凹槽、无围边、无脚架。
一条完整长边为一体式90度向下折弯挂边，形成连续的薄金属挂钩结构。
这条挂边不是向上凸起的挡条，不是托盘边框。
禁止普通砧板、烤盘、托盘、带把手金属板、小号方板、厚金属盒。
```

### 7.4 两镜头外观连续性

第一镜头允许产品先被货架遮挡后逐渐清楚，但横移结束时必须露出主轮廓和至少一个关键结构。第二镜头必须完整展示同一套产品。两镜头之间不得因硬切改变数量、尺寸、长宽比例、横竖方向、厚度、边缘形态、颜色、正反面关系和关键结构的位置。

生成前必须静默比对：第二镜头人物手里的产品，是否仍然能被描述为第一镜头货架上那一件。不能则重写。

禁止把单只产品变成一对、三只、多件套，除非资料明确说明并且本次脚本必须展示整套。

## 8. 场景与人物规则

全片固定同一名主角、同一套服装、同一发型、同一 Target 商超货架通道、同一展示位、同一光线和同一产品。

主角服装根据产品品类选择普通美国消费者穿搭，避免红色上衣与红色购物篮混淆。她不得穿 Target 员工制服，不得佩戴名牌，不得像品牌代言人。

商店环境允许通过明亮红白色调、红色购物篮和整洁通道表达 Target 氛围，但不得生成可读的 Target 字样、圆靶 Logo、真实零售商品牌、虚构品牌词、乱码字母、价格牌、促销牌和货架顶部文字。

## 9. 单一执行路径规则

Omini 提示词必须给模型一个固定答案。禁止出现：

```text
A或B
可以展示正面也可以展示背面
轻微擦拭或只介绍
在商店或家庭厨房
人物微笑或惊讶
拿一只或拿两只
```

每项必须固定为一个场景、一个主角、一个痛点、一个主卖点、一个展示动作、一个口播版本和一个结尾动作。中文提示词不得使用“或”来提供多选路径。

---

## 10. 内部安全改写

生成最终提示词前，静默完成以下检查：

- 删除竞品与材质拉踩；
- 删除未经资料支持的防护承诺；
- 删除绝对效果：`100%`、`completely`、`instantly`、`perfectly`、`always`、`never`、`guaranteed`；
- 删除虚假社会证明：`Everyone wants one.`、`These are selling out.`、`This is going viral.`；
- 删除虚假稀缺：`last one`、`only one left`、`low stock`、`almost sold out`；
- 删除不必要的强 CTA：`Buy now.`、`Order before it sells out.`、`You need this right now.`。

正确表达是：一个产品展示位内整齐放置一套开放展示样品，主角发现后自然取下介绍，结尾只表达日常使用价值。
