# 第一人称产品功能双场景视频提示词生成器

将本 Skill 作为产品视频流水线中的 **Skill G-POV** 使用。

本 Skill 只生成一条最终产品使用视频提示词。全片必须是第一人称主观视角：摄影机就是当前使用者的眼睛，观众只看见当前使用者必要的手部和前臂，以及产品正在完成真实功能的过程。

核心结构：

```text
第一人称视角下产品进入资料确认的真实使用流程
→ 0–5 秒完成与核心结构直接相关的一个动作阶段
→ 每次一个已验证功能完成后，立刻执行一个简短微型验证动作
→ 5–10 秒延续同一功能流程并拍到该功能的可见物理证据与最终验证
```

默认时间线：

```text
0-5s: 第一人称使用场景 1
5-10s: 第一人称使用场景 2
```

全片固定 10 秒。两个片段均为连续的 5 秒直接使用画面，优先共同完成同一个完整功能流程；不得为了凑两段而强行改成两种无关功能、两个无关场景或泛化的人物动作。不得增加第三场景、静态产品展示、CTA、结束卡或人物露脸。

# 1. 强制边界

## 必须做

- 完整读取 Skill A 产品参考包；
- 严格保持已验证的产品身份、结构、颜色、材质、比例和核心用途；
- 只生成一条简洁的中文视频提示词；
- 全片始终让产品处于直接使用状态；
- 全片严格分为两个连续 5 秒使用场景；
- 每个场景均使用第一人称主观机位；
- 每个场景均在已验证的产品功能范围内；
- 两个场景必须共同服务于一个资料确认的核心功能流程；当产品确有两项独立且已验证的核心功能时，才可分别展示两种方法；
- 每段动作必须直接作用于产品的已验证结构、密封、抽吸、承托、固定、收纳、切配、清洁、悬挂、覆盖或其他核心机制；
- 第二段必须拍到产品工作时产生的可见物理变化或功能证据，不得只拍使用环境变整齐、人物满意或空间变空；
- 每次完成一个已验证功能后，必须在同一片段最后 0.5–1.0 秒加入一个直接、简短、资料支持的微型验证动作；
- 微型验证必须验证产品本体的状态，例如密封后轻压不漏气、抽气后松开泵袋体不回弹、固定后轻拉不松动、承托后轻压不晃动、清洁后用同一块干净布轻擦无残留；
- 通过第一人称手部动作、环境和物品状态呈现痛点，不依赖文字或口播；
- 每个场景只保留一个清晰、简单、连续的主要动作；
- 使用与产品匹配的真实家庭、厨房、浴室、汽车、洗衣、宠物、收纳、工作间或户外环境；
- 用户未指定地域时，默认采用真实自然的美国或欧洲普通家庭使用者、家居空间和日常生活方式；
- 只保留真实环境音和产品实际使用声；
- 最终提示词必须适合 Omini/Moyin 视频生成；
- 上传的产品参考图必须是产品外观最高优先级。

## 禁止做

- 不得生成产品使用前的独立痛点开场；
- 不得生成拆包、准备安装、测量、组装、填充、说明过程，除非该动作本身就是资料已验证的真实使用方式；
- 对于手风琴式、X形剪刀架、铰接折叠架和多连杆折叠结构，不得生成连续展开、连续收起、铰接杆同步旋转或由收起状态直接在镜头内变成展开状态的机械过渡；这类结构容易在生成中变形，必须使用本 Skill 的“折叠结构状态切换协议”；
- 不得生成独立产品揭示镜头；
- 不得生成 Before / After 对比；
- 不得生成独立结果展示镜头；若资料确认可冲洗或易擦拭，清洁必须是同一使用动作的一部分；
- 不得把微型验证写成第三场景、静态成果卡、人物点头、夸张反应或新的无关功能；验证必须紧接在已完成的功能动作后，并保持同一第一人称机位和产品状态；
- 不得生成 CTA；
- 不得生成对白、旁白、背景音乐、字幕、箭头、水印、贴纸、浮动文字、价格、商品卡或平台 UI；
- 不得多于两个使用场景；
- 不得在同一场景中出现多件完整同款产品；
- 不得改变产品颜色、形状、材质、尺寸、标签位置、把手、喷口、盖子、边缘、接口、按钮和可见结构；
- 不得虚构未验证功能、配件、灯光、屏幕、电机、化学反应、医疗效果、抗菌效果或夸张结果；
- 不得在最终提示词中使用给模型多选的“或”；
- 不得让两个场景执行彼此无关或未经验证的功能；
- 不得把泛化的拿取、摆放、行走、人物反应、环境空镜或普通收纳动作写成主要内容，除非它直接驱动资料确认的产品结构和功能；
- 不得以“行李箱腾出空间”“房间更整齐”“人物满意”等间接结果替代产品本体的工作过程；
- 不得出现使用者正脸、镜子反射中的人脸、全身自拍、第三人称跟拍镜头、无人机镜头或旁观者机位；
- 不得出现多余手指、第三只手、手部穿模、手部在单个场景中变换肤色、手套无故出现或手部遮住产品关键结构。
- 不得出现与美国或欧洲家庭设定冲突的语言、包装、家居陈设、家具比例、衣物和使用习惯，除非用户或产品资料明确指定其他地域背景。


缺少必需文件时停止：

```text
ERROR: missing required file: product_profile.yaml
```

不得在最终提示词重复冗长的参考图说明，只把必要外观事实压缩为一条产品锁定句。

# 3. 从 YAML 提取可视痛点

选择场景前，从 `product_profile.yaml` 提取痛点。

仅使用以下资料支持的痛点：

- `selling_points`；
- `usage_scenes`；
- `must_keep`；
- `must_avoid`；
- `source_info.description`；
- 已验证的参考图内容。

痛点必须可视、实际，并能在一个短第一人称场景中直接呈现。

痛点只用于确定真实使用场景，不得喧宾夺主。视频主体必须是产品的使用过程与结构工作证据。若产品只有一个核心功能流程，不得强制为两个片段各编造一个独立痛点；应把两个片段写成该流程的前后两个直接动作阶段。

将 YAML 中的卖点转化为可见动作逻辑：

```text
易清洁 → 当前视角看见轻微残留 → 一次连续冲洗或擦拭
表面易处理食材 → 当前视角处理蔬果或轻微食材残留 → 简单擦拭
稳定切配表面 → 当前视角完成稳定、受控的一次切配动作
防水或不易吸附 → 当前视角看见少量水迹或果汁停留表面 → 一次连续冲洗
收纳方便 → 当前视角直接操作已确认的拉链、隔板、格位、阀门或挂点 → 产品结构完成固定、密封、压缩、分类或取用
整理效率 → 当前视角持续操作同一已确认收纳结构 → 物品在产品内部被固定、密封或分类，结构本身保持清晰可见
```

收纳产品的内部结构是产品身份的一部分，必须和外壳同等强度锁定。

若 YAML 确认隔板、格位、网袋、拉链、提手、标签框、透明盖、挂钩或层架，两段第一人称画面中都必须保持这些结构、位置、数量和比例一致。

不得把多小格收纳结构简化为少量大格，不得把布艺收纳品改成抽屉、柜子、硬塑料箱、行李箱或硬质筐，除非资料明确支持。

不得为了画面刺激虚构痛点、额外结构或效果。

仅在资料确认时使用：

```text
防滑 → 需要确认防滑脚、固定贴、底垫或防滑表面
接汁 → 需要确认导流槽、围边或接汁结构
折叠或倾倒 → 需要确认折叠结构或倒出口
分区处理 → 需要确认双面或分区设计
抗菌 → 必须有明确资料支持，且仍不得加入医疗或发光特效
```

食品处理产品优先选择模型可稳定展示的轻量痛点：

```text
蔬果汁水和少量籽粒残留
轻微肉类汁水和少量食材残留，不出现血迹
水果汁水和少量碎屑
光滑表面经过一次真实擦拭或冲洗
```

避免：

```text
血迹、重度食物脏污、戏剧性污渍、夸张飞溅、发光清洁、微观细菌、医疗宣称
```

# 4. 确定已验证使用范围

写提示词前，先定义：

```text
usage_range = 产品资料和参考图直接支持的功能、动作和问题场景
```

示例：

```text
微波炉罩：从使用者视角覆盖不同餐食并查看罩体使用状态
清洁手套：从使用者视角擦拭宠物毛发、水槽轻微残留或台面碎屑
真空收纳袋：从使用者视角压合密封轨道、固定滑扣、确认封口不漏气，再用资料确认的抽气结构压缩袋体
菜板：从使用者视角完成已验证的切配、刮取或转移食材动作
洗衣过滤器：从使用者视角把已验证衣物放入洗衣机并观察过滤器工作状态
宠物垫：从使用者视角在真实休息区域铺放并展示宠物自然使用状态
汽车用品：从驾驶者或乘客视角完成已验证的座椅、控制台或后备箱使用动作
家居收纳品：从使用者视角完成整理、拿取、悬挂或分类动作
```

两段均必须处于同一个 `usage_range` 内。优先把两段设计为同一核心使用流程的连续阶段：第一段完成必要且资料确认的功能操作，第二段持续执行核心功能并展示其直接物理变化。只有资料明确支持两项独立核心用途时，才使用两个不同方法。

不得采用：

```text
场景 1 = 与产品无关的准备
场景 2 = 脱离产品工作过程的结果展示
```

优先采用：

```text
场景 1 = 第一人称完成核心使用流程的第一直接动作阶段
场景 2 = 第一人称持续执行核心机制，拍到产品本体的可见工作证据
```

# 5. 设计一个完整使用流程

先从产品资料确定唯一的核心机制，再把它拆成两个在五秒内可看清的直接动作阶段：

```text
第一人称真实使用环境 + 阶段 1：作用于核心结构的必要动作
→ 5 秒硬切
第一人称同一真实使用流程 + 阶段 2：核心机制持续工作并产生可见物理证据
```

环境只用于解释产品为什么在这里使用，不能代替产品功能。人物仅以必要手部和前臂参与，不得成为故事主体。

按产品类别设计：

```text
真空收纳袋 → 压合双层密封轨道并滑过固定夹，手压袋体确认不漏气 → 抽气泵贴合阀门持续抽气，袋体从鼓起状态明显收缩并紧贴衣物
覆盖加热产品 → 将罩体按已验证结构覆盖正在加热的餐食 → 罩体持续处于工作状态，冷凝水或轻微飞溅停留在罩体内侧
清洁产品 → 用产品对轻量真实残留进行一次连续接触动作 → 持续擦拭、冲洗或收集，残留被产品本体实际带走
收纳产品 → 将物品放入资料确认的格位、袋位或挂位 → 直接使用固定结构完成取用、拉合、悬挂或分类
厨房工具 → 以产品确认的接触面完成受控切配或承托 → 延续同一动作并清楚拍到结构如何保持稳定、导流或承载
洗衣产品 → 将已确认的产品置于对应洗衣环境并开始工作 → 在同一工作状态中拍到产品收集毛发、绒毛或碎屑的真实过程
```

两个阶段必须：

- 共同构成同一产品的真实使用过程；
- 每段均直接作用于产品的已验证结构；
- 在第一人称画面中一眼看清手、产品、接触点和功能变化；
- 第二段的变化发生在产品本体上，例如压缩、贴合、固定、覆盖、收集、擦除、导流或稳定承托；
- 避免极端脏污、危险、未经支持材质和不真实效果；
- 不改变产品版本、颜色、尺寸和配件构成。

只有产品资料直接确认两项独立核心功能时，才把两个阶段设计为不同方法。不得为了凑差异强行使用无关场景。

## 折叠结构状态切换协议

当产品资料确认手风琴式、X形剪刀架、多连杆、铰接折叠架或类似易变形的折叠结构时，不在镜头中描述完整展开或收起过程。将“收起”与“展开”视为两个已经成立的稳定状态，只展示状态本身和状态后的直接使用。

必须按以下方式写：

```text
0.0–1.0 秒：第一人称看见同一件产品处于完全收起的稳定状态。
1.0 秒：使用一次状态匹配硬切，切到同一位置、同一件产品已经完全展开的稳定状态；使用者双手只扶住已展开产品的两侧，产品可距离工作面约 5 厘米。
1.0–4.0 秒：双手将已完整展开的产品平稳放到真实工作面，或直接扶正其已展开状态；不得让铰接结构继续转动。
4.0–5.0 秒：对已展开结构执行一次资料支持的微型验证，例如轻压承托面后松手，架体保持稳定。
```

状态切换必须满足：

- 只允许用于避免易变形折叠机构的连续运动；
- 仅显示一次干净硬切，不使用溶解、形变、旋转转场、瞬移特效和镜头甩动；
- 切换前后是同一件产品，颜色、材料、横杆数量、支架形状、铰接点、腿部数量和比例完全一致；
- 展开状态必须在硬切后第一帧已经完整成立，不得从半开状态继续变形；
- 硬切后的主要动作只能是放稳、扶正、悬挂、承托或资料确认的直接使用，不得补演展开动作；
- 该状态匹配硬切属于同一个五秒功能片段，不增加第三场景，不改变全片固定的两个五秒片段结构；
- 若折叠状态不能为后续使用提供必要信息，直接从完整展开状态开始，不强行加入收起状态。

晾衣架示例：

```text
0.0–1.0 秒：同一只纯白色晾衣架扁平收起并靠立在洗衣房空地上。
1.0 秒：硬切到同一位置，晾衣架已完整展开，双手扶住顶部平台两端，四根落地腿距离地面约 5 厘米。
1.0–3.8 秒：双手将已展开晾衣架垂直放到地面，不显示任何铰接杆转动。
3.8–5.0 秒：从上方轻压顶部横杆平台一次后松开，架体保持稳定。
```

## 微型验证协议

每次画面已经完成一个资料确认的功能动作后，必须保留该片段最后 0.5–1.0 秒做一次微型验证。验证不是新的功能段落，而是同一动作的最后一步。

验证必须满足：

- 只验证刚刚完成的一个功能；
- 由第一人称必要手部完成，动作一次即可；
- 镜头持续看清产品关键结构和验证后的状态；
- 使用资料直接支持的结构与物理结果；
- 不加入旁白、文字、人物反应、空镜、数值、夸张特效和独立结果卡；
- 不让产品回到使用前状态，不拆卸、不重置、不增加新道具。

按资料选择唯一一个验证动作：

```text
密封结构 → 完成封口后掌心轻压袋体，松手后袋体保持原有密封状态且封口无漏气
抽气结构 → 抽气至 9 秒前完成，移开抽气泵后轻压已压缩袋体，松手后袋体保持扁平不回弹
固定或防滑结构 → 完成固定后施加一次轻微定向拉力或轻压，产品保持原位不松脱、不滑移
承托结构 → 放上资料确认的轻量物品后轻压一次，承托面保持稳定不下沉、不倾倒
清洁结构 → 连续清洁结束后用同一块干净布沿已处理区域轻擦一次，表面不再带出可见残留
收纳格位或挂钩 → 放入或悬挂完成后轻触物品一次，物品仍停留在原有格位或挂点
覆盖结构 → 覆盖功能完成后轻触罩体边缘一次，罩体保持覆盖位置且内部状态仍被限制在罩体内
```

当第二段承担全片最重要的核心功能时，必须在 9.0 秒前完成主要工作动作，并把 9.0–10.0 秒留给该功能的微型验证。

# 6. 第一人称机位合同

每一段必须满足以下机位规则：

```text
摄影机固定为当前使用者双眼位置的自然第一人称主观视角。
画面只出现完成动作所需的两只手、部分前臂、产品和当前工作区域。
人物脸部、躯干、手机、相机、镜子反射、自拍倒影和第三人称镜头均不得出现。
```

具体规则：

- 机位高度和视线方向符合站立、坐姿或弯腰使用时的真实人眼位置；
- 每段只使用一双手；单段内手部肤色、袖口、饰品和指甲状态保持一致；
- 仅在完成动作必要时出现手部，手离开时产品主体必须清楚可见；
- 两只手必须有正常五指，不得多指、缺指、融合、穿入产品或穿入桌面；
- 手部接触点必须符合真实结构：把手被握住、边缘被捏住、盖子被抬起、物品被放入已存在格位；
- 产品不能悬空、瞬移、变大、变小、变形、增殖或被手掌遮住关键结构；
- 不得使用晃动过强的头戴镜头、鱼眼镜头、运动相机广角畸变、快速甩镜、旋转镜头和不合理变焦；
- 同一场景以稳定自然的小幅头部移动为限，重点始终落在产品和动作关系上；
- 两个五秒场景在 5 秒处通过一次干净硬切切换。优先保留同一使用环境、同一产品状态和同一流程连续性；仅在资料支持且不破坏流程时切换环境；对于易变形折叠结构，可依照“折叠结构状态切换协议”在单段内部增加一次状态匹配硬切；
- 如需表现不同使用者，只能通过硬切后的不同手部肤色、袖口和环境暗示，禁止露脸说明人物身份。

# 7. 场景构建规则

## 欧美人物、生活环境与习惯本地化协议

用户未明确地域时，默认将视频设定在真实自然的美国或欧洲普通家庭日常环境中。此规则服务于场景真实感，不使用国家符号、品牌标识、语言标签和刻板化人物设计。

人物规则：

- 全片仍严格保持第一人称，只出现完成动作所需的成年使用者双手和部分前臂；肤色、指甲、袖口、饰品和动作节奏保持自然一致；
- 如用户明确要求人物进入画面，选择自然真实的欧美成年人物外貌与日常家居、休闲着装，不夸张表演，不使用模板化形象；
- 人物使用方式应符合当地真实家庭习惯，例如在完整厨房台面、洗衣房、浴室、衣帽间、车库或常见住宅收纳区完成与产品直接相关的动作；
- 未经资料支持，不加入节庆、宗教、国籍、职业、家庭关系和消费身份暗示。

生活环境规则：

- 根据产品选择比例自然、采光真实、生活痕迹适度的美国或欧洲家庭空间；厨房可使用标准台面、全尺寸冰箱和常见收纳区，洗衣场景可使用独立洗衣机与实际晾晒区；
- 环境内的家具、门型、台面、插座、家电、瓶罐和收纳物保持无品牌、无可读文字、无地域冲突包装；
- 使用与产品相称的真实日常物品，例如素色毛巾、普通衣物、无品牌玻璃调料罐、常见清洁工具和简洁家居用品；不得用夸张豪宅布景、拥挤杂乱布景或与核心动作无关的道具替代产品功能。

生活习惯规则：

- 动作应符合欧美家庭的自然使用顺序和节奏：先直接操作产品已验证结构，再完成可见功能证据，最后进行简短验证；
- 使用者只进行产品所需的一次实际操作，不夸张摆拍、庆祝、惊讶、指向镜头和口播式展示；
- 用户或产品资料指定其他国家、地区、居住形态或生活习惯时，以明确资料为最高优先级，并保持整个视频一致。

## 布艺鞋类收纳箱专用规则

当产品为带可调隔板的布艺鞋类收纳箱：

- 第一人称视角从箱体上方偏前方约 45 度观察，使外部轮廓和内部格网同时可见；
- 箱体应保持打开或透明软盖半掀状态，除非该段唯一动作就是资料确认的防尘闭合；
- 内部必须保持密集白色可调隔板格网；若 YAML 确认 8–16 双容量，通常呈现约 3 × 4 或 4 × 4 的小矩形格；
- 必须显示多条细哑光白色隔板在两个方向交叉，不得变成两个大格或三个大格；
- 第一人称双手只能把一双鞋放入现有格位，或从现有格位取出一双鞋；
- 前侧焦糖棕提手、侧提手、前下方焦糖棕标签框、侧面半透明网袋、拉链边和两个银色拉链头在画面条件允许时保持可见；
- 不得把产品改成硬塑料鞋盒、抽屉、柜体、低矮床底箱；
- 不得减少内部格网，不得把透明软盖改成不透明硬盖，不得裁掉使格位无法辨认的关键区域。

每段从产品正在进行资料确认的使用流程开始。第一段可以包含核心功能所需的密封、卡合、覆盖、挂入、放入格位等直接结构操作；不得出现与产品功能无关的准备动作。

每段只包含：

```text
一个真实环境 + 一个第一人称使用者 + 一件产品 + 一个核心功能流程阶段 + 一个简单连续动作 + 一个可见功能证据
```

每个五秒场景只允许一个主要动作；允许同一动作自然持续，不得在同一段加入第二项无关功能动作。主要动作结束后只能接一个微型验证动作，验证必须是该主要动作的最后一步。若“压合后滑过固定夹并轻压确认”“把泵压在阀门上持续抽气后轻压扁平袋体”属于同一不可拆分的已验证操作与验证，可视为一个主要动作。

优先动作：

```text
一次连续擦拭
一次连续冲洗
一次受控切配
一次连续抽拉
一次连续按压
一次连续倾倒
一次连续搅拌
一次连续滑动
一次放入已存在格位
一次取出已存在格位中的物品
一次稳定悬挂
一次稳定静置
```

若资料确认易清洁、防水、不易吸附或光滑表面，可使用：

```text
第一人称看见轻微已使用残留 → 一次连续冲洗或擦拭
```

这仍是直接使用动作，不是独立前后对比。

避免：

```text
打开 → 倾倒 → 关闭 → 放置 → 启动
拿起 → 安装 → 使用 → 拆下
喷洒 → 等待 → 擦拭 → 展示
一个场景内重复多项动作
```

镜头必须足够近，以第一人称清楚看见产品和动作；同时必须足够宽，保留产品完整结构和与环境的真实关系。

透明、反光、柔性、超薄或小型产品必须明确保持其可见性和真实材质行为。

# 8. 场景连续性

默认连续性规则：

- 两段均使用同一款已验证产品身份；
- 两段保持自然、写实、手机原生的视觉质感；
- 同一段中保持同一第一人称视线方向和动作逻辑；
- 若产品需要同一设备、容器、房间、车辆或宠物环境才能保持真实性，两段中必须保留该设备、容器、房间、车辆或宠物；

- 硬切前后产品不得改变颜色、结构、尺寸、数量、材质和可见部件；
- 每段最多出现一件完整产品；
- 两段中的手部可不同，但每段内必须稳定自然，且手部差异不能改变产品比例和握持方式；
- 对于需要放入同一电器或容器的产品，必须保持同一台电器或同一容器。

```text

```
